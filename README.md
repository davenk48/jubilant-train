# Coursework for 7CCSMHFF - High Frequency Finance

Final Grade for Module: 75% (87% coursework + 70% exam)

Note that the purpose of CW2 was NOT to build a profitable trading strategy, but to build any strategy based on a certain framework from the lectures ([Directional Change Intrinsic Time](https://en.wikipedia.org/wiki/Directional-change_intrinsic_time)) and evaluate it well. Using the numba library allows for the strategy to execute much faster provided that the code is converted to pure python/NumPy, which in turn allows for a more comprehensive evaluation of strategy performance using more data.
